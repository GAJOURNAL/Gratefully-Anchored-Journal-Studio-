HOW TO DEPLOY

1. Unzip this ZIP on your computer.
2. In Netlify, on the screen that says "Upload your project files", drag the UNZIPPED folder named ga_journal_studio_v1 into that upload area.
3. Let Netlify deploy it.
4. Then open the new project in Netlify.
5. Go to Site configuration / Project configuration > Environment variables.
6. Add a variable named OPENAI_API_KEY and paste your secret key as the value.
7. Save and redeploy.
8. Open the live site and test it.

Do not paste your OpenAI key into any website file.
